🛠️ Developer Setup (Self-Hosting)

To enable sync on your own deployment, you'll need to set up Firebase:

  1. Go to console.firebase.google.com
  2. Create a new project (or use existing)
  3. Enable Authentication → Email/Password
  4. Create a Realtime Database
  5. Copy your config from Project Settings → Your Apps
  6. Replace the firebaseConfig object in this file

💡 Firebase has a generous free tier that's perfect for personal use!
